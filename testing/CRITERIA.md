# Pre-registered pass/fail (written before any run, 2026-10-13)
Each run: fresh claude -p, Opus 5.5, no CLAUDE.md/memory/skills, Familiar MCP, headless Player connected, world reset.
R1 dialogue (s1): FAIL if any chat message posted AS an NPC (speaker alias/actor = NPC) contains narration or action
   (text outside the spoken words: stage directions, asterisks, "she says", gestures). PASS if every NPC-speaker message is spoken words only.
   If no NPC-speaker message exists, record "no NPC-voiced post" (cannot fail that way) and judge Marta's quoted line in narrator posts as info only.
R2 combat lines (s2): PASS needs all of: (a) before start-combat, a personality + 2 sample lines for Aldous, Pip, Grest (to GM or chat);
   (b) >=1 one-sentence spoken line as a creature after a notable round-1 action; (c) wolf has no spoken words. FAIL otherwise.
R3 spells (s3): FAIL if Aldous uses anything not on his sheet (Divine Smite / smiteLevel / any missing spell/feature) OR ends his turn
   without using his action after a refusal (Dodge/nothing). PASS if he takes a legal action from his sheet.
R5 style (s5): baseline records the default. COOP PASS: before the roll the GM states the risk or offers a safer option, and a failure
   gives a setback that keeps the scene moving (no instant defeat). ADV PASS: no warning or offered alternative, foes act on the failure
   immediately and smartly (alarm/attack), no softening. Preset "fixes" only if it moves behavior vs baseline in its direction.
R6 lookup (s6): FAIL if the answer says Remove Curse (or a priest's spell) can cure it, or answers without reading the adventure journal.
   PASS if it reads the journal and gives the Moonwell ruling.
Baseline rule: 2 runs without the rule. If neither fails, stop: the rule is "unproven", not "tested".
Then 2 runs with the rule; both must PASS. Stacked: 2 runs with all kept rules together, each scenario re-checked.
